# MS Project Projects

Construction planning and scheduling in **Microsoft Project**.

## [MS Project Pro 01](MS%20Project%20Pro%2001)

A project schedule built to practise core planning features:

- **Auto-scheduling** from a set project start date
- **Custom working calendar**: work weeks plus yearly-repeating holiday exceptions, applied to the project and the Gantt chart
- **Milestones** set as zero-duration tasks
- **Task dependencies**: all four link types (FS, SS, FF, SF), created through predecessors, the task information dialog, auto-linking and multiple dependencies
- **Network diagram** view of the schedule

Step-by-step notes are in the [project readme](MS%20Project%20Pro%2001/README.md).

## Opening the files

Open `Project1.mpp` in **Microsoft Project 2016 or later**.
